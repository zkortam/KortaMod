The KortaMod name and logo belong to Zakaria Kortam. The code in this repository is GPL-3.0 (see [LICENSE](LICENSE)), and you're welcome to fork it, change it and share it.

If you publish a fork or your own build, please:

- give it a different name, and don't use the KortaMod logo;
- don't present it as official or as endorsed by KortaMod.

Only builds signed with the official KortaMod key are official, and only those receive updates from kortamod.app.

Saying your project is "based on KortaMod" is fine. Questions: [zakariakortam.com](https://zakariakortam.com).
